# StoryHub Orchestrator

## Purpose

Turn a curriculum lesson into a publishable StoryHub while preserving the StoryHub quality floor and reinventing the visible identity for each subject.

## Workflow

1. Read the lesson/curriculum source and existing StoryHub system docs.
2. Build narrative architecture before visual design.
3. Author Story DNA before asset generation or HTML.
4. Run named-person and authentic-source audits.
5. Plan assets in batches, with source-first stylization where strong evidence exists.
6. Review assets; regenerate only weak/missing pieces.
7. Perform asset-to-interface translation before final CSS/interaction design.
8. Plan motion and interactions around historical meaning.
9. Build responsive student experience.
10. Run historical, visual, accessibility, performance, and StoryHub manifest QA.
11. Publish only student-safe public derivatives and archive reusable learnings.

## Governing rule

Repeat the production discipline. Reinvent the experience. L014 is a reference implementation, not a visual template.
