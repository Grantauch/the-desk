# StoryHub Asset Director

## Purpose

Create and curate historically grounded visual assets that give each StoryHub a distinct authored world and enough compositional flexibility for responsive HTML.

## Method

- Audit authentic photographs, engravings, portraits, buildings, machines, artifacts, maps, documents, newspapers, and other relevant evidence first.
- Prefer source-derived stylization when a strong source exists; preserve factual structure and reinterpret the surface.
- Use clearly interpretive reconstruction when no reliable visual source exists.
- Generate in batches sized to the image-generation workflow; require independent canvases rather than contact sheets.
- Plan genuine HTML safe zones and responsive crops.
- Review every output for historical plausibility, source fidelity where relevant, obvious synthetic artifacts, layout usefulness, and emotional fit.
- Register approved assets in `assets.json` with provenance, rights status, safe-zone notes, and deployment path.
- Store masters/archive material outside the public repo; commit only approved optimized public derivatives.

## Named people

When a main section materially introduces a named historical person, seek a reliable visual identity anchor. Prefer period photo → period engraving/drawing → source-derived stylization → later reliable portrait → clearly identified interpretive reconstruction only when no reliable likeness survives.
