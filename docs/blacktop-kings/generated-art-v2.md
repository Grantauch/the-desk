# Blacktop Kings artwork expansion v2

Ten additional original images were made with the built-in image generator, using the approved v1 Lincoln Lot painting and actual game rendering as style references. Four menu illustrations, five player-style illustrations and one transparent basketball add 1,792,930 optimized bytes. Both batches contain 23 images totaling 4,727,154 bytes. The original PNGs and full prompt set remain outside the public repository in the additive review package.

The art direction continues v1: warm brick and gold light, rich painted urban materials, thick ink contours, angular cel shading, charcoal/navy shadows, restrained halftone and vivid jersey accents. New illustrated characters are fictional promotional figures. The customizable player still supplies the Career tile, creator preview and player cards.

Menu illustrations load when their screen is painted. Image-ready events update decorative images without rebuilding the form, preserving typed names, selections and keyboard focus. The existing canvas illustrations remain the loading/error fallback. Player-style cards omit the image panel until its image is available. The basketball retains its existing position, radius, rotation and physics; Crown shots retain their special gold ball treatment.

Focused local browser checks decoded all 23 images, inspected desktop and 390-pixel menu/creator layouts, preserved input identity/value/focus through an image-ready event, and verified player-style selection. Ball drawing used the new sprite for ordinary shots and retained the special-color path. Blocking every v2 asset preserved the original menu art, all five player-style controls and all four identity fields without creating a career save. Asset loader, court geometry and soundtrack regressions passed. The canonical gate and protected release checks are recorded separately in the release ledgers.
