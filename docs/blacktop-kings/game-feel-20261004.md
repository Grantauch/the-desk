# Existing-action presentation pass

The game-feel work planned as phase #178 improves the existing game actions without adding a new game mode, rating, economy or scoring rule. It ships with the competitive balance lab in PR #177. GitHub PR #178 was independently used by the October 5 lesson release; that release is preserved in the combined game branch.

- Smoother wrist follow-through, lower defensive foot lift, stronger plants and stops, a catch-to-secure motion with a higher rebound reach, landing compression proportional to descent, and contact recoil.
- Brief 35–55 ms impact pauses and modest camera punches for dunks, big blocks, ankle breakers and Crown activation. Motion reduction removes those pauses, zooms, slow motion and flashing, and also stops scoreboard reminder pulses.
- Distinct floor, shoe-landing, green-release, clock and rattled-net sounds. Backboard sounds use actual collision speed, and a banked score no longer repeats the board impact sound. Rim and floor feedback comes from the real collision steps.
- Cut/stop squeaks, a bounded crowd increase during tight late games and Crown/clock danger, a clearer final-three-seconds clock, a small brief human perfect-release ring, and a short cleared-possession reminder.

The original pre-release shot motion/timing remains intact after the gameplay regression caught an early draft making a mistimed block succeed. The extra cut timer is cosmetic and consumes no gameplay randomness; the original dust trigger remains intact. A seeded Kings/Showtime comparison reproduced the same 64 release/score/block/steal/rebound events after the final cut correction. That comparison is focused evidence, not a claim that every cosmetic pose has identical geometry.

Dedicated regressions verify perfect-only feedback, bounded impacts, reduced motion, side-cut random-draw preservation, physical floor contacts, one board sound per impact, one clock cue per whole-second crossing, paused shooting clocks, bounded clutch crowd, continuous follow-through and landing compression. Full canonical verification passed, including 600 real-engine balance games, existing gameplay/pose/art/asset/soundtrack checks, 53 built routes, 103 HTML files/4,347 references and all seven sealed StoryHub releases. Release archetypes range from 31.3% to 70.3%; a separate 240-game deep archetype sample ranges from 31.3% to 70.8%. Every original balance threshold remains intact. Actual Chrome quick-game start, shooting, pause and quit were exercised in full/reduced effects without captured JavaScript errors.
