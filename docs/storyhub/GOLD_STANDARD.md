# StoryHub Gold Standard v2

## Quality floor, not a template

StoryHub repeats research discipline, narrative control, source transparency, accessibility, performance, and QA. It does not repeat L014's navy palette, industrial motifs, sticky-image rhythm, two-door comparison, typography, controls, or section compositions by default.

The guiding line is:

> Repeat the production discipline. Reinvent the experience.

## Story DNA

Before asset generation or visible HTML/CSS work, define:

- tone
- palette
- typography
- texture
- shape language
- motion grammar
- interaction signature
- density rhythm
- archival behavior
- ending language

The identity should arise from the subject and the approved visual evidence.

## Asset-first art direction

Images create the historical world. HTML carries information. Scrolling can carry time. Motion can carry causation, scale, direction, pressure, or change. Interaction should carry understanding.

Prefer source-first stylization when a strong photograph, portrait, engraving, building, machine, street, map, artifact, document, newspaper, battlefield, or other authentic visual source exists. Preserve factual structure and reinterpret the surface. When no reliable source exists, use a clearly interpretive reconstruction rather than fake archival evidence.

## Named-person visual anchor

When a main narrative section materially introduces or discusses a named historical person, provide a reliable visual identity anchor while students are learning the name whenever a likeness exists.

Preference order:

1. period photograph
2. period engraving/drawing
3. source-derived stylization
4. later reliable portrait
5. clearly identified interpretive reconstruction when no reliable likeness survives

## Asset-to-interface translation

The HTML should feel born from the approved asset set. Before final CSS/interaction design, translate the images into the interface:

- sample palette from the assets
- let edge treatment and texture influence boundaries and controls
- choose typography that belongs beside the artwork
- let spacing follow each scene's composition rather than a universal grid
- use safe zones as intentional layout territory
- make controls look native to the story world
- solve image/HTML transitions as art-direction problems

The target is to erase the seam between artwork and interface.

## Motion grammar

Ask: **What should move in this story, and what historical idea does that movement teach?**

Possible motion families include expansion, geography, accumulation, compression, collision, stoppage, fragmentation, branching, replacement, and reveal. They are vocabulary, not a checklist. A familiar motion can return when its function and art direction genuinely belong to the new story.

## Interaction value

An interaction earns its place when changing it changes what a student can understand, compare, notice, predict, or remember.

For every interaction answer:

1. What historical idea does it teach?
2. What does the student change or choose?
3. What meaningful information, comparison, consequence, or feedback appears?
4. Would static text communicate the idea just as well?
5. Does the visual form belong to this StoryHub's identity?

A control that only animates or decorates is unfinished. Improve strong interaction ideas instead of deleting them just because they are flashy.

## Creative pressure tests

Prefer questions over blanket visual prohibitions:

- Does this composition belong to this historical moment, or is it merely convenient?
- Does this interaction teach something static text cannot teach as well?
- Does this treatment serve the story, or merely make it look expensive?
- If a familiar mechanic returns, has it been re-authored for this lesson?
- Does the interface look born from the assets?

Hard prohibitions are most useful for factual accuracy, privacy, accessibility, safety, broken responsive behavior, and proven technical failure modes.

## Technical floor

- student-readable without the teacher present
- semantic HTML and visible focus states
- keyboard and touch operable
- reduced-motion meaning preserved
- no core information dependent on hover
- responsive from small Chromebook windows through Promethean display
- natural scrolling; no scroll-jacking
- optimized public image derivatives
- transparent sources/corrections
- smooth enough for school Chromebooks

## Reference implementation

USH9 L014 — Unions & Collective Bargaining is Reference Implementation 001. It proves the medium and the process. It is not the visible template for future StoryHubs.
