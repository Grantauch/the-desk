Open package and staging checks

Package 1.0.0-rc.2 contains classroom application 1.0.0-rc.1 with corrected setup recovery and package verification.

1. Make an approved private copy

Use a Chrome profile signed into only your school Google account, or an Incognito window with only that account. Ask your school coordinator for the blank template checked against this package. Do not use an existing teacher's live workbook.

Copy approved blank template

A link alone does not prove source integrity. School IT must compare all seven template files with SOURCE-MANIFEST.json before deployment. If that check is unavailable, stop here and ask the coordinator. This page never provisions a Google project itself.

2. Configure your classroom

On your new copy’s opening page click the large Start setup / show my links button. You do not need to find a Sheets menu. After Google approval, click the same button again. If an older copy has no button, its backup is Hall Pass → Start setup (Ctrl+Shift+F expands a hidden toolbar). Enter your name, class schedule, school student-email domain and pass rules. Grant Google's requested permissions only from your school account.

If Google cannot read your settings

For PERMISSION_DENIED, open your existing copy in a Chrome profile or Incognito window signed into only your school account, then click Start setup / show my links again. Approve Google’s permissions if asked and reopen setup. Keep your copy and its tabs. If it still fails, give the error and copy link privately to school IT. See recovery instructions.

3. Open your staging web app

Follow the built-in setup wizard. In Google's deploy screen choose Web app, Execute as Me and Who has access: Anyone within your school, if permitted. Return to the setup window and click Find my app link. It checks that the link belongs to this copy, then saves the teacher dashboard and door kiosk links on the opening page. Bookmark the dashboard for daily use; Sheets holds the records in the background.

A school administrator may need to approve Apps Script and Chromebook kiosk use.

4. Open your classroom app

Use the links saved by the setup window. Your teacher dashboard is your everyday app. The form below is an optional shortcut tool for a link you already checked in your own setup window.

Open protected synthetic test

The protected test runs only as this teacher. Its separate synthetic workbook test does not prove shared-directory or cross-teacher acceptance. Follow the full staging checklist.

Save Chromebook kiosk shortcut

Send the kiosk link privately or open the shortcut in Chrome on the door Chromebook. Bookmark it and use Chrome's full-screen control (F11 on Windows; the full-screen key on Chromebook). The kiosk's keep-awake request may be limited by school policy. IT should confirm sleep, relaunch and account restrictions.

5. Connect your school directory

On your teacher dashboard open Settings → school directory / enroll by number. Connect the private directory link from your school coordinator, then enroll only synthetic test identities by their exact school number and period. Real enrollment and lunch-PIN cutover require separate district approval and a coordinated plan. Unassigned students stay inactive. Use the same exact lunch number in every connected room. Run the two-teacher tests in Preflight before release review. Imports create no memberships; never bulk-activate the directory.

Do not sign a teacher account into the student Chromebook. District IT handles managed kiosk policy and screen-sleep settings.

6. Finish the staging checks

Use package and staging checks to record test outcomes and save a private review record. Do not include names, lunch numbers or screenshots of student records.

Shared directory corrections are automatic. Independent software copies still require a separate deployment update. The requirement for centrally managed software updates remains unresolved; this candidate is not a finished rollout.
