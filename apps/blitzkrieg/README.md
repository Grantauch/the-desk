# Blitzkrieg — September 1, 1939

Originally built in Grok App Builder. This standalone edition retains the original one-road scenario, game engine, and art. The briefing and end card link to the United States Holocaust Memorial Museum for background on the September Campaign.

From The Desk repository root, install the normal site dependencies and run `node apps/blitzkrieg/build.mjs` after editing the game. Commit the updated JavaScript and CSS alongside the source. Netlify serves the result from `public/hubs/blitzkrieg/`.

The game stores only local progress. It uses React and React DOM 18.3.1 from the cdnjs distribution and eight Lucide 0.510.0 icon shapes. The third-party notices live with the static release.
