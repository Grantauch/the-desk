One system. Independent classrooms.

This preview introduces the Schoolwide Hall Pass and Check-In workflow. It is not an installer for the live school system. No student sign-in is enabled here.

No student records in this package. Do not type real student names, lunch numbers, PINs, or passwords into this preview. Existing classroom Hall Pass remains the active system.
Teacher dashboard

Door Chromebook

What this preview can do

Walk through equipment setup, demonstrate a fictional privacy reset, and prepare an approval checklist. It cannot log students in, grant passes, validate real PINs, or publish Schoolwide.

02 / Physical classroom

Two screens. Two different roles.

Keep the kiosk and teacher controls separate. A kiosk should never inherit the teacher's signed-in browser session.

At the classroom door
  • Dedicated Chromebook and reliable power
  • Restricted student-facing kiosk session
  • No saved passwords or staff profile
  • Screen positioned away from public viewing of private data
  • Network tested on the school's Wi-Fi
At the teacher desk
  • Independent authenticated staff device
  • Only assigned classes and sections visible
  • Pass timers and history on staff screen only
  • Teacher-controlled correction and return actions
  • Sign-out procedure when leaving the room
Not ready for production access. Do not bookmark a guessed student kiosk URL. The production address will be supplied only after the district-approved cutover.
03 / Existing credentials

Keep the lunch PINs students already know.

The working Hall Pass already has the lunch-number PINs. Teachers should not recreate or reset them for Schoolwide.

  • Five- and six-digit PINs must remain exact text, including leading zeros.
  • Students are visible in Schoolwide only after approved identity matching and active section membership.
  • One student can belong to two teachers' classes without a separate PIN for each teacher.
  • The old Hall Pass keeps working until the new credentials and history are verified under an authorized rollout.
Credential transfer has not been activated. Existing PINs are not being imported by this ZIP. Never export PIN Cards, real PIN hashes, or secret salts to a classroom setup file.
