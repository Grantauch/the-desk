# SW-010 — Isolated Schoolwide foundation

Status: **IMPLEMENTED ON ISOLATED BRANCH; CI REQUIRED**  
Branch: `schoolwide/sw-010-foundation`  
Legacy production baseline: `36088546070ac0f1b29b53d4f34018024092f84f`

## Objective

Create a new application lane that can evolve independently while the Version 18 classroom system continues serving students unchanged.

## Included

- TypeScript/Node service boundary.
- Fastify liveness/readiness HTTP surface.
- Standard PostgreSQL connection abstraction.
- Numbered SQL migration runner with advisory migration lock.
- Initial school/user/role/student/identity/section/staff-assignment/enrollment/audit schema.
- Composite tenant foreign keys for school-owned relationships.
- Canonical internal student UUID plus external identity aliases.
- Container and local PostgreSQL 18 development configuration.
- School-scope/role primitives with cross-school rejection tests.
- Environment invariant forbidding legacy production writes.
- Repository production-firewall gate.
- Dedicated path-scoped GitHub Actions workflow.

## Explicitly excluded

- No real users or student records.
- No Hall Pass/Check-In business logic.
- No Google OAuth/Classroom calls.
- No migration/import adapter.
- No PIN verifier migration.
- No change to the current website launcher or production routes.
- No change to the Apps Script source/workbook/deployment.

## Exit gates

1. Dedicated CI installs dependencies and type-checks.
2. Unit tests pass.
3. PostgreSQL migration applies successfully to an empty disposable database.
4. Re-running the migration is a no-op/succeeds.
5. Production firewall reports no out-of-lane modifications.
6. TypeScript production build succeeds.
7. Branch remains unmerged until the next architecture review.

A merge into `main` would add only dormant Schoolwide source/workflow files; it would still not activate Schoolwide or alter Version 18. Merge authorization is a separate decision.
